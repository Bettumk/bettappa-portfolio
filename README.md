# BETTAPPA Portfolio

A premium, responsive React + Vite portfolio for BETTAPPA, a Computer Science & Engineering student graduating in 2027.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite.

## Build for deployment

```bash
npm run build
```

The production files are created in `dist/`.

## Included

- Responsive dark portfolio
- Supplied profile photo
- Supplied resume PDF
- About, skills, projects, education, achievements and contact sections
- GitHub and LinkedIn links
- Resume download button

## Before publishing

Verify the CGPA shown in the portfolio against your latest academic record. The supplied resume contains both 8.04 (7th semester) and 8.02 in different sections, so the portfolio currently uses 8.04 because it appears in the detailed academic qualification section.
